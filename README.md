# Hamed Hosseini — Personal Website

A minimal, single-column personal page: plain HTML, CSS, and vanilla JavaScript. No build step, no backend. Deployable directly from the root of the `Hamed-hosseini.github.io` repository.

## Publish with GitHub Pages

1. Create the `Hamed-hosseini.github.io` repository under the `Hamed-hosseini` GitHub account.
2. Add the contents of this directory to the repository root.
3. Enable GitHub Pages from the `main` branch, `/ (root)`.
4. The site will be served at `https://Hamed-hosseini.github.io`.

## Structure

```
index.html            single page, numbered sections
css/style.css         full stylesheet (light + dark)
js/main.js            theme, mobile nav, scroll spy, reveal
assets/images/        photos (CV portrait, profile photo)
assets/documents/     downloadable Academic / Business CV PDFs
```
